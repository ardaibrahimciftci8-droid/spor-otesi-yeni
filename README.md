# 🏆 Spor Ötesi - AI Destekli Spor ve Wellness Platformu

Modern, kullanıcı dostu ve AI destekli tam kapsamlı bir spor ve wellness uygulaması.

## 🎯 Özellikler

### 🧘 Yoga & Meditasyon
- AI destekli kişiselleştirilmiş yoga programları
- Yoga koçu ile interaktif sohbet
- Farklı seviyeler (Başlangıç/Orta/İleri)
- Özelleştirilebilir program süreleri

### 💪 Egzersiz Takibi
- Aktivite kaydetme (Koşu, Yürüyüş, Bisiklet, vs.)
- Uyku takibi
- AI egzersiz koçu
- İstatistikler ve grafikler

### 🍎 Beslenme
- Kalori hesaplama (BMR/TDEE)
- Öğün analizi
- AI beslenme koçu
- Makro besin takibi

### 👥 Sosyal Özellikler
- Kullanıcı profilleri
- Post paylaşımı (Resim/Video)
- Takip sistemi
- Entegre mesajlaşma
- Yorum ve beğeni

### ⚽ Maç Analizi
- AI maç analisti
- Taktiksel analiz
- Skor tahminleri

### ❤️ Bağış Sistemi
- Türkiye'nin 81 ili için bağış
- Spor altyapısı desteği

## 🤖 AI Koç Sistemi

Her bölümde uzman AI koçlar:
- **Yoga Koçu**: Yoga ve meditasyon
- **Egzersiz Koçu**: Antrenman programları
- **Beslenme Koçu**: Diyet ve beslenme
- **Maç Analizi Koçu**: Spor taktikleri
- **Sohbet geçmişi kaydediliyor**
- **Kullanıcı bazlı öneriler**

## 🛠️ Teknolojiler

### Frontend
- React 18
- Tailwind CSS
- Framer Motion
- Firebase Authentication

### Backend
- FastAPI (Python)
- MongoDB
- Cloudinary
- Pollinations AI API
